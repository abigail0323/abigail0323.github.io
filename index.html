PROJECT 01 · Global E-commerce / International Marketing

동남아 온라인 시장 개척 · GTEP 19기

국내 중소기업의 헤어볼륨핀(MINK-I)을 베트남 · 태국 · 싱가포르 Shopee에서 판매한 프로젝트입니다.

OverviewMy RoleProcessResultsKey LearningsGallery

Project Overview

해외 인지도가 낮은 국내 헤어 액세서리 브랜드를 동남아 3개국 Shopee에서 판매했습니다. 2025년 3월부터 11월까지 국가별 검색어와 고객 반응을 분석해 광고와 프로모션을 조정했고, 낮은 인지도와 매출 하락 속에서도 판매 방식을 재정비했습니다.

My Role

  • Shopee 3개국 운영
  • 현지 검색 키워드 · 고객 반응 조사
  • 검색광고 · 프로모션 운영
  • Shopee Live 홍보
  • 제품 상세페이지 개선
  • 매출 · 고객 리뷰 분석

Process

  1. 국가별 키워드 맵 작성hair volume, hair clip 같은 검색어를 베트남어 · 태국어 · 영어로 대응시키고, 시장마다 반응이 높은 단어를 표시했습니다.
  2. 데이터 기반 검색광고 운영초기에는 AI 추천 키워드로 노출을 넓히고, 이후 전환율이 높은 검색어를 중심으로 예산을 다시 배분했습니다.
  3. 월간 캠페인 참여7.7 같은 Shopee 월간 프로모션에 맞춰 5–10% 할인 바우처, 무료배송 쿠폰, 타임딜 한정 쿠폰을 운영했습니다.
  4. Shopee Live 홍보물 제작7월 28일 라이브 방송을 알리는 홍보 포스터를 제작했습니다.
  5. 리뷰 분석과 상세페이지 개선리뷰와 판매 실적을 검토해 옵션 혼선이 생기는 문제를 발견하고, 상세페이지를 직접 개선했습니다.

OverviewMy RoleProcessResultsKey LearningsGallery

Project Overview

2026년 제1차 대전·세종 글로벌 진출 전략 프로그램에 참여한 32개 중소기업과 1:1로 바이어 발굴 상담을 했습니다. 기업마다 제품과 목표 시장이 달라, 획일적인 검색 대신 거래 이력과 유통 구조까지 탐색 범위를 넓혔습니다.

My Role

  • 32개 기업 직접 상담
  • 제품 · 목표 시장 분석
  • B/L 거래이력 분석
  • HS Code 기반 시장 조사
  • 경쟁사 수출처 조사
  • 유통채널 탐색
  • Apollo.io · RocketReach 활용
  • Excel 바이어 DB 작성

Process

  1. 기업 상담제품의 특징과 희망 시장, 기존 거래 경험을 확인했습니다.
  2. HS Code로 시장 좁히기품목의 HS Code를 기준으로 수입 수요가 있는 국가와 시장을 조사했습니다.
  3. B/L 거래이력과 경쟁사 수출처 분석비슷한 제품을 실제로 수입한 기업과 경쟁사의 수출처를 찾아 후보 바이어를 추렸습니다.
  4. 유통채널 탐색산업마다 다른 유통 구조를 확인해 접근할 채널을 정했습니다.
  5. 담당자 정보 확보와 DB 제공Apollo.io와 RocketReach로 담당자를 찾고, 후속 영업에 바로 활용할 수 있도록 기업별 Excel 바이어 DB로 정리해 제공했습니다.

Key Learnings

현지 지사장님은 싱가포르의 환경 규제와 지속가능성에 대한 관심이 커지면서 가구 렌털 사업의 의미도 커지고 있다고 설명하셨습니다. 그러나 그 기업은 친환경이라는 가치에만 머물지 않았습니다. AI 기업과 협업해 렌털 가구에 카메라를 결합하고, 고객사가 마케팅 성과를 확인할 수 있는 KPI 데이터를 제공하며 차별화하고 있었습니다.

PROJECT 05 · Business Strategy / Marketing

청원생명쇼핑몰 경쟁력 강화 전략 제안

충북 지역 농특산물 쇼핑몰의 경쟁력을 높이기 위한 전략을 수립한 캡스톤디자인 프로젝트입니다. 실행 성과가 아닌 전략 제안 프로젝트입니다.

OverviewMy RoleProcessResultsKey LearningsGallery

Project Overview

청원생명쇼핑몰은 청주시가 인증 · 관리하는 로컬푸드 쇼핑몰로, 공공 브랜드의 신뢰도는 높지만 온라인 인지도와 마케팅 역량이 낮았습니다. 중간 유통 마진으로 생산자 수취가는 낮고 소비자 가격 부담은 큰 구조에서, 쇼핑몰의 경쟁력을 높일 방안을 찾았습니다.

My Role

  • 운영기업 대표 인터뷰
  • 소비자 53명 설문조사
  • PEST · SWOT · STP · 4P 분석
  • 디지털 마케팅 개선안 제시
  • 공동물류 · 운영 효율화 아이디어 제안

Process

  1. 현황 분석3C와 SWOT으로 강점(인증 받은 공공 브랜드)과 약점(D2C 역량, 데이터 축적 부족)을 정리했습니다.
  2. 현장과 고객의 목소리운영기업 대표를 인터뷰하고 소비자 53명을 대상으로 설문조사를 진행했습니다.
  3. STP와 4P 재설계30–60대 지역 주부에 집중된 타깃을 MZ세대와 1인 가구로 넓히는 방향과, 제품 · 가격 · 유통 · 홍보별 문제점을 도출했습니다.
  4. 개선 방향 제안신뢰와 상생 기반의 프리미엄 브랜드 구축, 세분화된 제품 라인과 정기구독, 스마트팜 연계 유통, 참여형 디지털 홍보를 제안했습니다.

Results

우수상2025 경영대학 캡스톤디자인 경진대회 (2025.11.27)
53명소비자 설문 응답

Key Learnings

좋은 제품과 신뢰받는 브랜드가 있어도, 그 가치가 고객에게 닿는 경로가 없으면 경쟁력이 되지 않는다는 것을 배웠습니다. 이미 가진 강점을 새로운 고객의 언어로 다시 설명하는 일이 전략의 출발점이었습니다.

AI 활용 수출 마케팅 콘텐츠 기획

ChatGPT와 Claude를 활용해 수출기업의 마케팅 콘텐츠와 수출지원 안내 콘텐츠를 기획했습니다.

OverviewMy RoleProcessKey Learnings

Project Overview

기업마다 다른 제품 정보와 목표 시장을 AI가 이해할 수 있게 정리하고, 이를 바탕으로 마케팅 이미지와 안내 콘텐츠를 만드는 과정을 설계했습니다.

My Role

LEARNED · 교육에서 학습AI 활용 기초

  • ChatGPT 프로젝트 기능 활용
  • 기업별 지식 파일 구성
  • 질문 기반 프롬프트 설계

APPLIED · 실제 수행 업무수출지원 콘텐츠 기획

  • 수출기업 마케팅 이미지 제작 프로세스 설계
  • Claude 활용 수출지원 콘텐츠 기획
  • 수출바우처 안내 콘텐츠 및 서비스 추천 유형 기획

Process

  1. 기업 정보 정리기업별 제품, 강점, 목표 시장을 지식 파일로 구성했습니다.
  2. 질문으로 설계한 프롬프트AI가 필요한 정보를 먼저 묻고 답을 만들도록 질문 기반 프롬프트를 설계했습니다.
  3. 콘텐츠 기획마케팅 이미지 제작 과정과 수출바우처 안내 콘텐츠, 기업 유형별 서비스 추천 방식을 기획했습니다.

Key Learnings

AI는 결과물을 대신 만들어 주는 도구라기보다, 기업마다 다른 정보를 빠르게 정리해 더 맞춤화된 지원을 가능하게 하는 도구라는 것을 배웠습니다. 좋은 결과는 좋은 질문과 잘 정리된 정보에서 나왔습니다.
